# MDquickAdd
Quick type to a  user defined .md file


## WHO 
[me](https://matchamakes.net/)

## WHAT 
Used angry typing to [Google Gemini](https://gemini.google.com/) to make a quick add python script to add to my [OBTF](https://obtf.ru/en/) triggered by pressing ctrl shift and, space simultaneously typing a thought then pressing ctrl and enter. This python script is to serve as a starting point for anyone else wanting to build something similar. 

## WHERE
Hosting on Github. For anyone any where to use. 


## WHEN
